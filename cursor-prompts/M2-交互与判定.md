你是资深 Godot 游戏开发工程师，继续制作教学项目「宝石迷阵三消」。这是第二阶段：在 M1（8×8 网格渲染）基础上，加入**点击选中、相邻交换、三消判定、消除计分**。

## 技术约束（必须遵守）

1. 引擎：Godot 4.7，语言 GDScript；沿用现有项目结构（gem.gd / board.gd / main.tscn）
2. 零外部资源；代码注释**全中文**；简单直白；不用 autoload；单文件 ≤150 行
3. 每个功能函数职责单一：`find_matches` / `try_swap` / `clear_matches`
4. 不破坏 M1 已有功能

## 本阶段目标（M2）

1. **输入处理**：在 main.gd 里用 `_unhandled_input` 处理鼠标左键点击，把点击位置经 `world_to_grid` 换算成网格坐标
2. **选中状态**：点击一个宝石 → 高亮选中（如放大/描边）；再点相邻宝石 → 触发交换；点空白或非相邻 → 取消选中
3. **交换逻辑** `try_swap(a, b)`：
   - 校验相邻（上下左右）
   - 交换后调用 `find_matches()` 检测
   - 有匹配 → 保留交换，进入消除；**无匹配 → 动画交换回去（不算步数）**
4. **匹配检测** `find_matches()`：
   - 逐行扫描：连续 ≥3 同色宝石标记整段
   - 逐列扫描：同样逻辑
   - 返回去重后的匹配宝石集合
5. **消除与计分** `clear_matches(matches)`：移除匹配宝石、grid 置 null、计分（每组3个=30分，多1个+10）、发出 `score_changed(score)` 信号
6. **步数扣减时机（统一约定）**：仅「交换后产生匹配」才扣 1 步；无效交换弹回**不扣步**。M2 阶段可先用 print 调试，M3 再加 MovesLabel
7. **UI 占位**：场景里加一个 ScoreLabel（Label 节点），main.gd 连接 `score_changed` 信号更新显示
8. 交换/消除要有基础动画（Tween 滑动/淡出），动画期间**禁止输入**（加简单状态变量锁）；动画用 `await tween.finished` 串行执行，不要并发多个 Tween

## 验收标准

- 运行后可点击选中宝石、与相邻宝石交换
- 三个同色连成行/列 → 消除并加分，分数实时显示
- 交换无匹配时自动弹回
- 动画播放期间点击无效
