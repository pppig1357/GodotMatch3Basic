## 本阶段目标（M3）

1. **下落与填充** `fall_and_refill()`：
   - 消除后逐列从下往上扫描，空位上方宝石下落（Tween 平滑移动）
   - 列顶生成新随机宝石，从网格上方落入（带下落动画）
2. **连锁检测**：
   - 填充完成后自动再次 `find_matches()` → 有匹配继续消除 → 再下落 → 循环
   - 直到棋盘稳定（无匹配）才结束，期间**持续锁输入**
3. **完整状态机**（main.gd 或 board.gd 内）：
   - `enum State { IDLE, SELECTED, SWAPPING, RESOLVING, GAME_OVER }`
   - SWAPPING（交换动画中）/ RESOLVING（消除+下落+连锁中）禁止输入
   - **动画串行执行（关键）**：用 async 管道 + `await tween.finished`，禁止并发多个 Tween（会导致宝石 position 与 grid 数据不同步）。推荐结构：

```gdscript
func resolve_board() -> void:
    state = State.RESOLVING
    var chain := 1
    while true:
        var matches := find_matches()
        if matches.is_empty():
            break
        await clear_matches_async(matches, chain)
        await fall_and_refill_async()
        chain += 1
    state = State.IDLE
```

4. **动画完善**：
   - 交换滑动动画（~0.15s）
   - 消除动画（缩放+淡出，~0.2s）
   - 下落动画（根据距离缓动，速度恒定观感）
5. **连锁加分**：连锁次数 n 对应倍率 ×n（教学点：变量累乘）
6. **胜负判定（统一约定）**：`moves_left` 初始 20，仅成功交换（产生匹配）减 1；**步数归零即结束**——剩余步数为 0 时，当前 RESOLVING 结束后进入 GAME_OVER（不额外等待棋盘无匹配）。UI 加 MovesLabel 显示剩余步数

## 验收标准

- 消除后上方宝石下落、顶部补新宝石
- 连锁能自动触发（下落产生新匹配时连续消除）
- 动画期间点击无效（状态锁生效）
- 步数显示/递减正常（可在 UI 加 MovesLabel，或先 print 调试）
