# Cursor Prompt · M1 网格渲染（第1课时交付）

> 使用方法：把本文档全文复制给 Cursor，让它在你指定的空目录里生成 Godot 项目。

---

你是资深 Godot 游戏开发工程师，正在为一个面向**零基础大学生**的社团社课制作教学项目「宝石迷阵三消」。这是第一阶段（共4阶段），目标是做出**可运行的 8×8 彩色网格**。

## 技术约束（必须遵守）

1. 引擎：Godot 4.7，语言 GDScript
2. 零外部资源：宝石用 ColorRect 纯色方块占位，不用贴图、不用插件
3. 代码注释**全中文**，关键逻辑附简短教学解释
4. 代码简单直白，避免 lambda/装饰器/高级语法；函数命名自解释
5. 不使用 autoload（全局单例）
6. 单脚本文件控制在 150 行内，超了拆函数/拆文件

## 本阶段目标（M1）

创建完整的 Godot 4.7 项目，包含：

1. **项目骨架**：`project.godot`、`icon.svg`、`scenes/main.tscn`、`scenes/gem.tscn`、`scripts/gem.gd`、`scripts/board.gd`
2. **主场景**：Main (Node2D) 包含 Board (Node2D) 子节点
3. **gem.tscn 场景（关键：场景实例化）**：宝石做独立场景——根节点 Node2D，挂 gem.gd，内含一个 ColorRect 子节点（纯色方块占位）。宝石类型用 `type`（6 种颜色枚举 RED/BLUE/GREEN/YELLOW/PURPLE/ORANGE）、`grid_pos: Vector2i`
4. **board.gd**：
   - `GRID_SIZE = 8`、`CELL_SIZE = 64`
   - `grid: Array` 8×8 二维数组
   - **用 `preload("res://scenes/gem.tscn")` + `instantiate()` + `add_child()` 生成 64 个宝石实例**（教学点：场景实例化 = Godot 核心工作流，官方 Step by step 重点）
   - 网格在窗口**居中**
   - `grid_to_world(pos)` / `world_to_grid(world)` 坐标换算函数
   - **`ensure_no_initial_matches()`**：生成后循环检测，若有初始三消则重随机/局部替换，直到无匹配（避免开局自动消除误导学员）
5. **ColorRect 必须显式设置 size**（如 `size = Vector2(CELL_SIZE, CELL_SIZE)`）：ColorRect 继承 Control，挂在 Node2D 下无锚定区域，不设 size 会不可见
6. **遵循 Godot 官方命名规范**：节点/类 PascalCase、变量/函数 snake_case、常量 ALL_CAPS
7. 运行后窗口显示 8×8 彩色方块阵列（无交互，纯渲染）

## 项目配置

- 窗口尺寸：建议 **640×720**（8×64=512 + UI 边距）
- 渲染：Compatibility（与后续 Web 导出一致）
- 输入：建 `click` 动作绑定鼠标左键（便于课堂讲解）

## 验收标准

- `godot --path .`（或编辑器 F5）能运行，看到 8×8 彩色网格
- 窗口大小合适（如 900×800），网格居中
- 代码中文注释完整
