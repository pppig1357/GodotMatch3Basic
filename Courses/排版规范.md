# 社课课件排版规范 v1.0

> **来源**：参考 Infoco 算法课《Lecture 1 暴力枚举与搜索》(qwqqaq) 的排版风格 + 三消课需求定制
> **定位**：做 pptx 和 PPT 页面序列时统一按本规范来——**开场页可以有个性，正文页进三色体系**
> **受众**：零基础新生（信息密度必须低）
> **状态**：v1.0（2026-08-16，小龙虾整理）

---

## 一、配色（三色原则）

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | 纯白 `#FFFFFF` | 无纹理、无渐变，极致干净 |
| 主色 | Godot 蓝 `#478CBF`（或社团青灰蓝 `#4A8A9E`） | 标题、页眉标识、流程箭头、重点框 |
| 强调色 | 正红 `#DC143C` | **只留给关键标注**：坑、警告、时间复杂度、验证标准 |
| 正文 | 纯黑 `#000000` | 不用灰色正文（投影看不清） |
| 辅助 | 手写体（签名/提问句） | 打破机械感，加人味 |

**规则**：全篇最多 3 个颜色出场。红色用多了就不"关键"了。

---

## 二、页面布局

- **固定页眉**：每页左上角放 **Infoco × 独游社** 标识 + 课程名——翻到哪页都知道在哪
- **标题**：左对齐，主色，字号明显大于正文（≥28pt 投影友好）
- **信息密度（最重要）**：每页 ≤2~4 个要点 **或** ≤2 个代码块，留白 ≥60%
  - 一页塞不下 = 拆两页。**零基础学员需要呼吸感**
- **无页脚页码装饰**——空间全留给内容
- **分区布局**：
  - 概念页：标题下直接 Bullet Points（上下结构）
  - 代码页：左右双栏（左代码右注释）
  - 对照页：双栏 + 中间粗蓝箭头

---

## 三、代码/伪代码块样式

- **等宽字体**（Consolas / JetBrains Mono），纯黑，**无语法高亮**
- **边框**：1px 纯黑实线框，**无底色、无阴影、无圆角**（"白板讲义"式）
- **中文注释**：代码旁/上方用中文自然语言注释（`# run 起点`），不用英文缩写
- **行号**：不显示
- **📍 代码地图标签（我们的独有设计）**：代码块左上角放 `📍 board.gd → ⑥ 匹配判定`——学员永远知道自己在代码的哪个位置
- **伪代码 vs 真实代码**：左右双栏对照，中间蓝箭头连接，差异处红字标注

---

## 四、激光笔式注解（分段精讲页）

- 代码右侧用**蓝色横线**指向对应部分，线端标注人话（如 `← run_start 起点`、`← 状态锁`）
- 效果：像讲师用激光笔在投影上指——一眼看懂代码段职责
- 对应我们的"分段精讲"页面设计：高亮本段、其余变灰

---

## 五、每页类型模板

| 页类型 | 布局 | 要点 |
|--------|------|------|
| 封面 | 非对称：左文字右插图 | 课程名 + 副标题 + 手写体签名 |
| 课程计划 | 列表式 | 关键信息下划线；4 课表格逐行出现 |
| 概念页 | 上下 Bullet | ≤4 条；关键术语用「」标注 |
| 代码全貌页 | 单栏大代码框 | 无动画（供阅读/复制） |
| 对照页 | 左右双栏 + 蓝箭头 | 伪代码↔真实代码 / 规则表↔代码分支 |
| 精讲页 | 代码 + 右侧注解线 | 非高亮段变灰，高亮段保持 |
| 验证/动手页 | 操作指令列表 | 验证标准用红字标 |
| 提问页 | 手写体问题 + 答案延迟出现 | "点击后出现"动画 |
| 结尾 | 极简留白 | 主色大字收尾（GL & HF 式） |

---

## 六、开场 vs 正文的分工

- **开场页（1~2 页）可以有情绪**：浅蓝底、个性文案（如"无底的不归路"）——负责建立气氛和筛选
- **正文页统一进三色体系**：白底 + 主色 + 红强调——负责清晰传递
- 两者不打架：**开场负责情绪，正文负责清晰**

---

## 七、动画原则（做 pptx 时）

- 渐次出现（规则表逐行 / 代码段逐步点亮），**不搞花哨转场**
- 对照页：先左后右，再箭头连线
- 精讲页：点击一次高亮一段，其余变灰
- 提问页：问题先出，答案点击后出现
- 每页动画 ≤3 步，别让学员等动画
