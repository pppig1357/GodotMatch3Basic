## 教学总原则（零基础版）

1. **概念最小化**：不讲理论课，所有编程概念（变量/数组/循环/if/函数）跟着实操走，用到才讲
2. **讲师先演示，学员再动手**：每个实操环节讲师完整做一遍 → 学员独立做 → 讲师巡视纠错
3. **实操链**：改一行（L1）→ 加一行 print / 读代码（L2）→ **写一个函数（L3）**→ 连线发布（L4）——难度递增、成就感递增
4. **board 黑盒法**：main.gd 精读、board.gd 查字典。学员只需认识 board 的 5 个对外接口（`reset_game` 开局 / `get_gem_at` 取宝石 / `try_swap` 交换 / `resolve_board` 结算 / `world_to_grid` 坐标换算），类比「用手机不需要懂电路」
5. **单元四段式（算法课节奏）**：每个知识单元固定走「**概念 → 问题/例子 → 模板 → 实操**」——先讲清是什么，再抛问题为什么需要它，给可背模板，最后动手
6. **伪代码先行**：核心算法先讲伪代码/流程图（思想不被语法淹没），再对照真实代码——零基础读 371 行 board 的门槛直接降一半
7. **练习三档**：课内实操（必做）→ 课后作业（巩固）→ 挑战 More（学得快的人），每课明示
8. **保底线 / 进阶线**：跟完主流程 = 过关；三档练习给学得快的同学
9. **先导视频**：开课前发环境安装视频，第一节课直接进实操

## 第1课时：场景与节点

**教学目标：** 装好环境，理解"游戏=节点的树"，看到 8×8 宝石棋盘，完成人生第一次改代码

**开场钩子：** 成品试玩 + 课程目标——直接目标（做出一个能玩的游戏 + 学会 Godot）/ 深层目标（理解游戏引擎原理，为独立游戏打底）

| 环节 | 内容 | 时长 |
|------|------|------|
| 开场钩子 | 成品试玩（先看到目标）+ 课程目标页 | 15min |
| 环境安装 | Godot 4.7 下载安装（官网/Steam）、首次启动、打开成品项目 | 20min |
| 编辑器四面板 | 场景/节点/检查器/文件系统，运行 F5 | 15min |
| 概念：场景与节点 | 场景树、父子关系、节点类型速览（Node2D/Sprite2D/Label/Button） | 15min |
| 例子+实操①：拆解宝石 | 打开 gem.tscn：Sprite2D 挂贴图（**资源直接拖进节点**）、SelectMask 遮罩 | 15min |
| 概念：场景实例化 | 为什么棋盘有 64 颗宝石？`preload + instantiate()`（场景=图纸，实例=产品） | 10min |
| 实操②：第一次改代码 | 打开 board.gd，`GRID_SIZE` 8→10，F5 看棋盘变大 | 15min |
| 小结 + 练习三档 | 回顾节点树/数组/循环；布置作业 | 15min |

**本课知识点（全部 0 基础起步）：**
- 游戏引擎是什么、Godot 编辑器布局（场景/节点/检查器/文件系统）
- 场景 = 节点树；节点有父子关系（子节点跟随父节点移动）
- **贴图 = 场景里挂的资源**：Sprite2D 的 texture 槽直接拖 PNG（gem_red.png 等 6 张独立图）
- **场景实例化**：gem.tscn 是"图纸"，`GEM_SCENE.instantiate()` 复制出 64 个实例（Godot 核心工作流）
- 变量与数组：`grid[col][row]` 二维数组存棋盘
- **伪代码先行：生成棋盘**（双层循环 8×8 → 每格随机颜色 → 摆到位置）→ 对照 `fill_grid` 真实代码
- `for` 循环生成 64 个宝石；`randi() % 6` 随机颜色（0~5 对应六色枚举 GemType）
- 坐标换算：网格坐标 (col,row) → 像素坐标（`grid_to_world`），`origin` 居中棋盘
- 命名规范：节点/类 PascalCase、变量/函数 snake_case、常量 ALL_CAPS

**演示代码：** `gem.tscn` + `gem.gd`（58 行）+ `board.gd` 生成区（fill_grid / _spawn_gem）

**练习三档：**
- 课内必做：GRID_SIZE 8→10
- 课后作业：`randi() % 6` → `% 5`（少一种颜色）
- 挑战 More：棋盘改 6×6

**常见坑：** 节点位置用 `position`；先 `add_child` 再 `setup`（@onready 依赖进树）；改完代码必须 F5 才生效

## 第2课时：交互与判定 ⭐（核心概念课）

**教学目标：** 点选交换、三消判定、交互状态机；**会读代码 + 加一行 print 调试**（不写完整函数——函数留给第3课）

**开场钩子：** 「怎么让宝石能点？」——点击 → 坐标 → 判断，一步步拆

| 环节 | 内容 | 时长 |
|------|------|------|
| 回顾 + 作业讲评 | 上节课棋盘、答疑 | 10min |
| 概念：输入处理 | 鼠标点击 → 屏幕坐标 → 棋盘坐标；InputMap `click` 动作 | 15min |
| 模板 T1/T4：状态机 | 交互规则表 + IDLE/SELECTED 切换表（可背）→ 逐分支精讲 | 30min |
| 伪代码+概念：三消判定 | find_matches 扫描（伪代码先行 20min）→ 对照真实代码 | 30min |
| **实操⭐：debug print** | 拆 3 行加 1 行 print，看输出面板打印点击坐标 | 20min |
| 小结 | 回顾：输入 / 状态机 / 判定三件事 | 5min |
| 弹性缓冲 | 实操超时、答疑、挑战 More | 10min |

**本课知识点：**
- 输入：`_unhandled_input` + `get_global_mouse_position()` + **InputMap 动作**（`event.is_action_pressed("click")`——用"动作"不用"按键"，可重映射，官方推荐）
- 坐标反算：屏幕坐标 → 网格坐标（`world_to_grid`：减 origin → 除以 64 → floor 向下取整），越界返回 (-1,-1)；**floor ≠ int**（负数场景 int 截断会出错）
- **交互规则表（T4，v3.2 正式版，纯点选无拖拽）**：
  - IDLE 点击宝石 → 选中（半透明白遮罩高亮，SelectMask——L1 埋伏笔，**本课完整讲**：`set_selected` 3 行 + 调用时机）
  - SELECTED 点击自己 → 取消选中
  - SELECTED 点击相邻 → 交换；点击非相邻 → 换选
  - 点击空白 → 取消选中
- **状态机模板（T1）**：IDLE / SELECTED 两态切换表（可背）；SWAPPING/RESOLVING 是"动画期间锁输入"（预告第3课）
- 相邻判断：曼哈顿距离 == 1（`board.is_adjacent`——board 是网格的权威，黑盒）
- **伪代码先行：三消扫描**（逐行扫连续同色段 run ≥3 → 逐列同样 → 汇总去重）→ 对照 `find_match_groups`
- **run 算法细节**：run_start/run_end 两指针，起点跳到 run_end 不回头（每格只扫一次）；**L 形去重**（`_add_unique`：横纵组共用一颗只能算一次）
- 交换合法性：`try_swap` 先交换→检查→无匹配弹回（**回滚套路**：先做→检查→不行就回滚，第3课连锁同思路）
- 调用链（跨三文件）：`_on_pointer_down` → `_do_swap`（main 只管流程）→ `board.try_swap`（规则权威）→ `gem` 动画——黑盒法：认识接口即可
- 开局防死局：`ensure_no_initial_matches`（无初始三消）+ `ensure_has_moves`（至少一步可走）——避免学员以为游戏 bug

**实操⭐：debug print（20min，零风险）**
- **需求**（讲师口述）：让输出面板打印出"你点的是第几列第几行"——第一次亲眼看到代码响应鼠标
- **伪代码先行**：点击 → 拿坐标 → 翻译成格子 → 打印 → 取宝石判规则（流程先讲清）
- **细节猛攻**：`world_to_grid` 坐标数学（减 origin / 除以 64 / floor / (-1,-1) 越界暗号）
- **步骤**：`_on_pointer_down` 开头把组合拳一行拆三行（翻译存 `grid_pos` 变量 → `print("点击了格子：", grid_pos)` → 用变量取宝石），F5 看输出面板
- **验证标准**：点宝石打印 (col,row)；点棋盘外打印 (-1,-1)
- **改坏了？** 删掉 print 和中间变量即可——零风险实操

**演示代码：** `main.gd`（输入分发 + 状态机 + 点选规则）+ `board.gd`（try_swap / find_matches / is_adjacent / world_to_grid）+ `gem.gd`（set_selected 遮罩）

**练习三档：**
- 课内必做：debug print（加 1 行）
- 课后作业：① 匹配长度改成 4 连才算消除（改一个数字，找找在哪）② print 改成打印颜色编号 `clicked.type` 或状态 `state`（观察 0→1 状态机切换）
- 挑战 More：print 同时打印 `board.is_adjacent(selected, clicked)`——观察点相邻/非相邻时 true/false

**常见坑：** 数组越界（0~7）；`abs()` 在警告当错误下编不过（用 `absi`）；`instantiate()` 需要 `as Gem` 显式转换；输出面板在编辑器底部（F8）；坐标"差一格"是 floor 正常现象（点在第 3 格右边缘算第 4 格）

## 第3课时：游戏循环 ⭐（核心实操课）

**教学目标：** 消除→下落→填充→连锁的完整循环 + 动画 + 状态锁；**独立写完人生第一个函数 `_calc_score`**（从第2课移入：计分绑定消除/连锁，主题更贴）

**开场钩子：** 「消掉之后上面空了怎么办？」——空位怎么补？新宝石从哪来？

| 环节 | 内容 | 时长 |
|------|------|------|
| 回顾 + 作业讲评 | 上节课交互/判定、答疑 | 10min |
| 概念+模板 T3：Tween 动画 | 交换/消除/下落动画；**await 串行模板（可背）** | 20min |
| 伪代码+概念：下落与填充 | fall_and_refill：逐列压实、顶部生成（伪代码先行） | 25min |
| 模板 T2：连锁与状态锁 | resolve_board while 循环、连锁倍率 ×n（计分挂钩） | 15min |
| **实操⭐：补全 `_calc_score()`** | 函数概念（10min）→ 模板 → 自己写 → 消除验证 | 40min |
| 小结 | 回顾：游戏循环、函数、await | 5min |
| 弹性缓冲 | 实操超时、答疑、挑战 More | 5min |

**本课知识点：**
- 动画：Tween（`create_tween()` + `tween_property`）；**动画串行模板（T3）：必须 `await tween.finished`**——禁止并发 Tween（会导致宝石位置与 grid 数据不同步）；同阶段多颗并行、阶段之间串行
- 消除动画：缩小 + 淡出（`set_parallel(true)` 同时进行）
- **伪代码先行：下落填充**（逐列自下而上压实空位 → 顶部从网格上方落入新宝石）→ 对照 `fall_and_refill`
- 下落算法：`FALL_PER_CELL = 0.08` 按格数近似恒速
- **结算循环模板（T2）**：`while 有匹配: 消除 → 下落`——连锁 = 循环重复；**连锁倍率：第 n 次消除 ×n**（`clear_matches(matches, chain)` 里乘）
- **函数概念（实操前置，10min 讲清）**：函数 = 输入 → 处理 → 输出；`func 名字(参数) -> 返回类型`——为什么需要函数（复用/分工）
- **计分规则（实操题）**：每组 3 个 = 30 分，每多 1 个 +10（4 连 = 40，5 连 = 50…）；连锁倍率挂钩在 `clear_matches`
- 状态锁：SWAPPING / RESOLVING 期间 `_unhandled_input` 直接 return（动画中不允许新输入）
- async/await：交换/消除/下落各是一个 async 函数，`await` 等动画播完再继续
- **拆文件进阶话题（不展开）**：board.gd 371 行算长吗？→ 工程上可以拆 RefCounted 辅助类（我们的历史版本拆过又合并）——留给学有余力的同学课后探索

**实操⭐：补全 `_calc_score()`（40min）**
- **需求**（讲师口述 + 白板）：输入一组匹配（每组 ≥3 个同色宝石），输出总分；计分规则：3 个 = 30 分，每多 1 个 +10
- **模板**（`Courses/实操模板/L3-calc-score.md`，提前发）：函数签名已写好、注释已标 TODO，函数体留空
- **步骤**：函数概念前置（10min）→ 讲师先完整写一遍（讲解 for/if/累加）→ 学员自己写 → F5 消除一组宝石看分数 → 讲师巡视 + 现场纠错
- **验证标准**：消除 3 连 = 30 分；消除 4 连 = 40 分（30+10）
- **进阶挑战**：把连锁倍率也乘进去（改 `clear_matches` 一行）——呼应 T2 模板

**演示代码：** `board.gd` 结算区（resolve_board / clear_matches / fall_and_refill / _calc_score）+ `gem.gd` 三个动画函数

**练习三档：**
- 课内必做：补全 `_calc_score`（人生第一个函数）
- 课后作业：① 加分规则改成 3 个 = 50 分 ② 连锁倍率改 ×2（改 `clear_matches` 一行）
- 挑战 More：给连锁加音效节奏（参考 `match_cleared` 信号）

**常见坑：** Tween 并发导致宝石乱飞（必须 await 串行）；下落必须从列底向上扫；交换/消除/下落三个 async 函数顺序不能乱；_calc_score 忘写 `return` / 返回类型不匹配；空数组输入要返回 0

## 第4课时：架构与发布

**教学目标：** 看懂整个游戏怎么串起来的（信号流），打包成 exe/Web 发给别人玩

**开场钩子：** 「整个游戏是怎么串起来的？」——回顾四课时，画出信号流全景

| 环节 | 内容 | 时长 |
|------|------|------|
| 架构全景图 | main（指挥）/ board（规则）/ gem（棋子）/ hud（界面）四角色 + 信号流 | 25min |
| HUD 搭建 | CanvasLayer 分层、锚点、StyleBox 资源（改 tscn 不改代码） | 25min |
| 信号机制详解 | emit / connect：hud→main→board 通信链，解耦原理 | 20min |
| 实操：改 HUD + 导出 | 改按钮样式/文字；导出 Windows exe / Web | 30min |
| 结课 | 进阶方向（M5 特殊宝石/模式）、官方教程自学指路、Gamejam 预告（GL & HF 式收尾） | 20min |

**本课知识点：**
- **架构四角色**：main.gd（106 行，指挥调度）/ board.gd（371 行，规则权威）/ gem.gd（58 行，棋子表现）/ hud.gd（28 行，界面）
- **信号流全景**：`hud.start_game → main.new_game → board.reset_game`；`board.score_changed → hud.update_score`；`board.match_cleared → main 播音效`——UI 与逻辑解耦（观察者模式）
- **官方 HUD 架构（对齐 Dodge the Creeps）**：独立 `hud.tscn` + 信号开局；Main 持有 `$Music` / `$SfxClick/Select/Swap/Clear`
- **CanvasLayer**：UI 独立成层，不被游戏内容遮挡
- **锚点 Anchor Presets**：定位 UI 控件（分数左上、按钮右下）
- **StyleBox 是资源不是代码**：改 tscn 即可（亮黄主按钮/亮蓝次按钮，深色字，深石板灰蓝背景对比度验证过的）
- 生命周期：标题界面不生成棋盘（`board._ready` 只算 origin），点开始 `reset_game → fill_grid`；「重新开始」直接开新局（restart 信号，不回标题——v3.2 简化）
- 音效/BGM：现成 ogg 直接挂 AudioStreamPlayer；BGM 外部引用 + loop
- 导出：Windows exe / Web（关 thread_support）；新素材先 `godot --headless --import`

**演示代码：** `hud.tscn` + `hud.gd`（28 行）+ `main.gd`（new_game / 信号连接）+ export_presets

**练习三档：**
- 课内必做：改一个按钮样式 + 导出 exe
- 课后作业：把成品发给讲师；给游戏起名字换标题
- 挑战 More：想一个进阶玩法（特殊宝石、限时模式）——下周 Gamejam 见

**常见坑：** 新加 .ogg 无 .import 时 preload 报错（需 headless --import）；导出后字体丢失（嵌入字体）；Web 导出要关 thread_support
