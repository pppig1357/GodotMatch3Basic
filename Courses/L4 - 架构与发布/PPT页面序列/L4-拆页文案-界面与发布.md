## E1 · 导出 exe / Web（压缩版）⭐

**标题：** 打包：让游戏离开你的电脑

**页面内容（步骤 + 坑，一页收完）：**

```
Windows exe：项目 → 导出… → Windows Desktop → 导出项目
  → GodotMatch3.exe + .pck（两个文件一起发，不用装 Godot）
Web（可选）：导出选 Web → ⚠️ 关闭 thread_support → .html+.wasm

三个坑提前说：
  ① 首次先装导出模板（版本要和引擎一致）
  ② 字体丢失 → 字体资源勾选"嵌入"
  ③ 新素材报错 → godot --path <项目> --headless --import
```

**讲师口播：**
- 「**导出 = 把整个工程变成一个 exe 文件**。别人双击就能玩，**不用装 Godot**——这就是"发布"的含义。导出后得到 `GodotMatch3.exe` + `.pck`（资源包），**两个都要发给别人，放同一目录**」
- 「**首次要先装导出模板**（编辑器 → 管理导出模板），模板版本必须和引擎一致，不然报错。我们的项目已配好 `export_presets.cfg`（Windows + Web 两个预设），你直接导出就行」
- 「Web 版可选：关掉 `thread_support`（静态托管跑不了线程版），导出 `.html + .wasm` 挂 itch.io / GitHub Pages，**发链接就能玩，手机也能玩**」
- 「三个坑提前说：**①模板版本 ②字体嵌入 ③headless --import**——踩过一个就全懂了」

**验证点：** 无，步骤页；实操②马上做。

## E2 · 实操②：导出 + 发给朋友

**标题：** 实操②：导出，然后发出去

**页面内容（操作指令，压缩）：**

```
① 导出 Windows exe（E1 步骤）→ build/GodotMatch3.exe
② 双击运行，完整跑一局：开始 → 交换 → 连锁 → 重开
③ 把 exe + pck 发给朋友 / 上传 GitHub Releases
   （可选）导出 Web 版 → 传 itch.io / 发链接

验证标准：
  ✅ exe 双击能玩，不用装 Godot
  ✅ 你的游戏名 + 你选的按钮颜色
  ✅ 字体不丢、音效正常
```

**讲师口播：**
- 「现在把四节课的成果**变成能分发的东西**：导出 exe，自己先完整跑一局，然后**发给你的朋友**——ta 不用装 Godot，双击就能玩。这就是 L4 的交付：**一台能带走、能炫耀的机器**」
- 「时间不够的同学：这步可以当课后作业，步骤和坑都在这页和实操模板里」

**验证点：** 红色标注验收标准三条。

## F1 · 结课回顾 ⭐

**标题：** 四节课，一条完整的路

**页面内容（四课进阶回顾）：**

```
L1 改一行：搭环境、建项目、生成 64 颗宝石
L2 读代码：点选、交换、三消判定——看懂规则怎么写的
```

**讲师口播：**
