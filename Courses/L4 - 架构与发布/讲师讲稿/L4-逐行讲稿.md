**板书建议：** 画四角色卡片 + 行数标注，标"行数 = 分工的复杂度"。

| 代码 | 人话（照读） |
|---|---|
| `signal start_game` / `signal restart` | 「hud 有两个"喇叭"：开始、重开。它只会**喊**，不会做——具体谁去开新局，它不关心。」 |
| `@onready var score_label: Label = $ScoreLabel` | 「拿 hud.tscn 里的控件引用——L1 学的 @onready 套路，等进场景再取。」 |
| `func prepare_playing()` | 「标题界面 → 对局界面：藏 3 个（遮罩/标题/开始按钮）、亮 2 个（分数/重开按钮）。」 |
| `score_label.text = "分数: %d" % score` | 「`%d` 是**占位符**——被后面的数字替换。`"分数: %d" % 30` = `分数: 30`。格式化字符串，以后写 UI 天天用。」 |
| `_on_start_button_pressed()` → `start_game.emit()` | 「按钮被点 → **喊一声** start_game。就这一件事——它不认识 main，也不知道 new_game 是什么。这就是解耦。」 |

**板书建议：** 画箭头：`按钮 → 喊一声 → （谁听到谁处理）`。

## 块4 · main.gd 信号连接（_ready）

| 代码 | 人话（照读） |
|---|---|
| `hud.start_game.connect(new_game)` | 「**接线**：听到 hud 喊 start_game，就执行 new_game。所有线都在 _ready 里一次性接好。」 |
| `hud.restart.connect(new_game)` | 「重开也是 new_game——简化版不回标题，直接开新局（这是 v3.2 的取舍）。」 |
| `board.score_changed.connect(hud.update_score)` | 「board 分数一变 → hud 刷新显示。**这条线跨了两个不认识的角色**——board 不知道 hud 存在，靠 main 牵线。」 |
| `board.match_cleared.connect(_on_match_cleared)` | 「开始消除 → 播音效。」 |
| `hud.update_score(board.score)` / `$Music.play()` | 「初始化：分数显示 0，BGM 开播。」 |

## 块5 · 导出

| 口播 |
|------|
| 「导出 = 把工程变成**一个 exe 文件**。别人双击就能玩，不用装 Godot。步骤：项目 → 导出 → Windows Desktop → 导出项目。首次要先装导出模板——版本必须和引擎一致，不然报错。」 |
| 「三个坑提前说：①模板版本 ②字体丢——字体资源勾嵌入 ③新素材报错——headless --import。踩过一个就全懂了。」 |

## 块6 · 实操引导（改 HUD）

| 口播 |
|------|
| 「最后一个实操：**改按钮样式 + 游戏标题**——不用写代码！打开 scenes/hud.tscn，选中 StartButton，检查器里换 StyleBox 资源（亮黄/亮蓝两色都行）；Message 节点改文字，把标题换成你给游戏起的名字。完成标准：按钮变色、标题是你的名字、F5 正常运行。」 |
