## 第 1 课 · 场景与节点

**演示顺序：**
1. 开场：成品试玩 → 「无底的不归路」劝退页 → 课程计划全景 → 「它是怎么做出来的？」
2. Godot 介绍（对比表：免费/2D强/零基础友好）
3. 编辑器四面板 → F5 运行成品
4. 拆解宝石（gem.tscn：身体/脸/面具/行为）→ 场景实例化（月饼模具比喻）
5. 实操①：GRID_SIZE 8→10（第一次改代码）
6. 小结 + 作业

**常见学员错误：**
- 节点位置用 `position` 而不是 `global_position`（L1 够用）
- 改完代码不按 F5（以为自动生效）
- 找不到 board.gd 在哪（引导用文件系统面板 + 搜索）

**提问点：**
- 「棋盘上 64 颗宝石，是 64 个文件吗？」（引出场景实例化）
- 「改一个数字，整个游戏都变——为什么？」（代码 = 规则）

**验收标准：** 打开项目 F5 能看到 8×8 彩色棋盘；改 GRID_SIZE=10 后棋盘变大。

## 第 2 课 · 交互与判定 ⭐

**演示顺序：**
1. 回顾 L1 棋盘 → 「怎么让宝石能点？」
2. 输入处理：InputMap 动作 + 坐标四步旅程（快过）
3. 状态机：**规则表先行**（可背）→ 逐分支精讲 → 调用链展开（_do_swap）
4. 三消判定：**伪代码 20min**（run 思想）→ 代码对照 10min → L 形去重
5. 实操：debug print（拆 3 行加 1 行）→ 输出面板验证
6. 小结（输入/状态机/判定）

**常见学员错误：**
- 输出面板找不到（F8；编辑器底部「输出」标签）
- print 写在函数外（报错）
- 坐标"差一格"——floor 正常现象，不是 bug
- 交换失败弹回以为 bug（是 try_swap 回滚，正常的）

**提问点：**
- 「点自己取消 vs 点空白取消，有什么不同？」（都回 IDLE，但路径不同）
- 「为什么 `is_adjacent` 要问 Board 而不是自己算？」（黑盒法）
- 「L 形三消，中间那颗算几次？」（去重——算 1 次）

**验收标准：** F5 点宝石面具亮；点自己取消；点相邻交换（无匹配弹回）；点棋盘外打印 (-1,-1)。

## 第 3 课 · 游戏循环 ⭐

**演示顺序：**
1. 回顾 L2 → 「消掉之后上面空了怎么办？」
2. 动画 T3：await 串行模板（可背）——**先讲为什么不能并发**
3. 下落填充：伪代码先行（记账本 → 逐列压实 → 统一播放）
4. 连锁 T2：resolve_board while 循环 → chain 倍率
5. 实操：函数概念 10min → _calc_score 填空（讲师演示 → 学员写 → 验证）
6. 小结（循环/串行/函数）

**常见学员错误：**
- `_calc_score` 忘写 `return total`（-> int 必须返回）
- `group.size()` 少括号
- `if n >= 3` 写成 `> 3`（3 连被跳过）
- 改 FALL_PER_CELL 后下落"消失"（改太小 = 瞬移）

**提问点：**
- 「为什么下落必须自下而上扫？」（从上往下会卡半路）
- 「为什么动画之间必须 await？」（同一颗宝石被两个 Tween 控制会穿帮）
- 「连锁第 2 次分数为什么 ×2？」（chain 递增——设计决策）

**验收标准：** 三消自动连锁转起来（消除→下落→补新）；_calc_score 补全后 3 连=30、4 连=40；改 FALL_PER_CELL 手感变化。

## 第 4 课 · 架构与发布

**演示顺序：**
1. 回顾三课 → 「整个游戏是怎么串起来的？」
2. 架构四角色（main 指挥 / board 规则 / gem 表现 / hud 界面）
3. 信号流四条线（观察者模式：喊一声 vs 打电话）
4. hud.tscn 节点结构 → 实操：改 HUD（不写代码）
5. 导出 exe / Web → 三个坑
6. 结课：四步回顾 + 进阶方向 + Gamejam 预告

**常见学员错误：**
- 信号名拼错（start_game vs startGame——蛇形）
- connect 写错位置（必须在 _ready 里、函数调用之前）
- 导出报错：模板版本不一致 / 字体没嵌入

**提问点：**
- 「hud 为什么不能直接叫 board 干活？」（解耦：改一边不碰另一边）
- 「信号和函数调用有什么区别？」（广播 vs 打电话）
- 「导出后别人电脑没装 Godot 能玩吗？」（能——exe 自带运行时）

**验收标准：** 改按钮样式 + 标题成功且游戏正常；导出 Windows exe 双击可玩。

## 全局提醒

- **零基础原则**：每节课概念最小化，所有概念跟着实操走；难代码伪代码先行
- **背三张表**（贯穿全课）：T1 状态机 / T2 结算循环 / T3 动画串行——每课结尾重复强调
- **黑盒法**：board 5 个接口反复用，不要求读懂内部（find_match_groups 等只看思想）
- **保底线**：跟完主流程 = 过关；三档练习给学得快的
- **时间控制**：每课 100min 内容 + 弹性缓冲；实操超时优先砍讲解，不砍实操
- **代码纪律**：课件代码与源文件逐行核对过（2026-08-16 校验）；若改代码，先更新课件再上课
