# 第2课 · 讲师逐行讲稿（照着念就能讲）

> **用途**：PPT 放代码，讲师按本讲稿的「人话」栏念——每一行代码对应一句大白话
> **配套**：代码块文档 `L2-交互与判定.md`（PPT 取代码用）；本讲稿（嘴上说什么用）
> **使用方式**：表格「人话」栏 = 口播稿，加粗处 = 停顿/强调；「板书建议」= 可写在白板或 PPT 备注
> **核心比喻（全课反复用）**：**Main = 指挥中心（只管流程），Board = 规则权威（什么都懂），Gem = 棋子（只会表现）**
> **节奏提醒**：本课 120min——回顾 10 + 输入 15 + 状态机 30 + 判定 30 + 实操 20 + 小结 5 + 弹性 10（详见课件大纲）

## 块1 · 输入处理（main.gd ⑤ + board.gd ④）

> PPT 显示 `_unhandled_input` + `world_to_grid` + `get_gem_at`（见 L2-交互与判定.md 块1）

| 代码 | 人话（照读） |
|---|---|
| `func _unhandled_input(event)` | 「所有没被界面抢走的输入，都从这扇门进来——键盘、鼠标、触摸，全走这。**这是我们跟游戏的对话窗口。**」 |
| `if state == State.SWAPPING or state == State.RESOLVING: return` | 「动画播放中？**直接无视**。这就是状态锁——游戏在忙，你别点。不然宝石还在飞你又点一下，它就穿帮了。」 |
| `event.is_action_pressed("click")` | 「`click` 不是鼠标左键，是**动作名**——在 InputMap 里配好的。代码只认名字不认按键：以后想改触摸，改配置就行，**代码一行不用动**。」 |
| `await _on_pointer_down()` | 「`await` = 等一下。点一下，进入我们的核心函数——下一块拆它。」 |

**板书建议：** 画「输入 → 状态锁 → 动作判断」三个框，标"只有通过检查才进点选"。

### 坐标换算（board.gd ④）

| 代码 | 人话（照读） |
|---|---|
| `var local := world - origin` | 「鼠标坐标是**屏幕**的，棋盘在**中间**——先减掉棋盘左上角的位置，变成『相对棋盘』的坐标。origin 就是那个左上角，L1 讲过。」 |
| `var col := int(floor(local.x / CELL_SIZE))` | 「**除以 64**——一格 64 像素，除一下就知道落在第几格。为什么用 floor？因为点在第 3 格右边缘也算第 3 格——**向下取整**。记住：floor 不是 int，负数场景 int 会出错。」 |
| `return Vector2i(-1, -1)` | 「点棋盘外了？返回暗号 **(-1,-1)**。后面拿这个暗号当『点空白』处理——你们实操时会亲眼看到它打出来。」 |
| `return grid[pos.x][pos.y] as Gem` | 「`get_gem_at` 更简单：拿格子坐标，去数据表里**掏宝石**。越界、空位都给 null。」 |

**板书建议：** 数轴：0~63=第0格 / 64~127=第1格……强调「每 64 像素一格」。

## 块2 · 状态机 + 点选交互（main.gd ①⑥）⭐

> PPT 显示 State 枚举 + `_on_pointer_down`（见 L2-交互与判定.md 块2）
> **先讲规则表再碰代码**：先展示交互规则表 T4 + 状态切换表 T1（可背），再逐行对照

| 代码 | 人话（照读） |
|---|---|
| `enum State { IDLE, SELECTED, SWAPPING, RESOLVING }` | 「游戏任何时刻，都在这四种状态**之一**——像红绿灯：空闲(绿)、选中(黄)、交换中/结算中(红，锁住)。**同一时间只有一个，这就是状态机。**」 |
| `var clicked: Gem = board.get_gem_at(board.world_to_grid(world))` | 「从里往外读：先把鼠标坐标**翻成格子**，再从格子**掏宝石**。一行干两步——这就是函数套函数，里面的先算。」 |
| `if clicked == null: _deselect(); state = State.IDLE; return` | 「点空白 = 反悔。熄灭面具、回到空闲。**记住：画面和数据永远同步改。**」 |
| `if clicked == selected: _deselect(); state = State.IDLE` | 「① 点自己 = 再点一下反悔。面具灭、回空闲——你们刚才 F5 试过吧？」 |
| `if board.is_adjacent(selected, clicked): await _do_swap(...)` | 「② 点相邻 = **交换**，本课核心！注意：『挨着吗』是**问 Board**——Main 不自己算，规则的事问权威。」 |
| `_deselect(); _select(clicked)` | 「③ 点非相邻 = 换选。旧面具灭、新面具亮，**还是选中状态**——把刚才那颗换成新点的这颗。」 |
| `_select(clicked); state = State.SELECTED` | 「空闲状态点宝石 = 选中。面具亮——L1 那个藏起来的面具，**今天第一次真正亮起来（伏笔兑现！）**。」 |

**板书建议：** 画状态切换图：`IDLE ⇄ SELECTED`（点宝石进 / 点自己、点空白出），标注 SWAPPING/RESOLVING 是"锁"。

## 块3 · 选中辅助 + 交换流程（main.gd ⑦⑧）

> PPT 显示 `_select` / `_deselect` / `_do_swap` + 调用树（见 L2-交互与判定.md 块3、状态机样板页6）

| 代码 | 人话（照读） |
|---|---|
| `selected.set_selected(true)` | 「`_select` 就干两件事：**记下**这颗宝石 + **点亮面具**。面具亮不亮是 `set_selected` 说了算——就是 L1 那个 SelectMask，今天它上班了。」 |
| `selected.set_selected(false); selected = null` | 「`_deselect` 反过来：灭面具 + 清空记忆。**成对出现**：有选就有取消，画面和数据永远一致。」 |
| `state = State.SWAPPING` | 「`_do_swap` 第一件事：**上锁**。交换动画 0.15 秒内谁也别想点。」 |
| `var ok: bool = await board.try_swap(a, b)` | 「核心活**包给 Board**：『帮我试试换这两颗』。注意 await——**等它干完再往下走**。结果就一个布尔：成了/没成。」 |
| `if not ok: state = State.IDLE; return` | 「没成？Board 已经把宝石**弹回原位**了，我们只需要解锁。为什么没成？——换完发现没有三消。下一块讲这个『检查』。」 |
| `state = State.RESOLVING; await board.resolve_board()` | 「成了！但先别解锁——还有消除、下落、连锁要播完（**第 3 课的主角**）。锁着等它。」 |
| `state = State.IDLE` | 「一切结束，解锁。**这就是交换流程：锁 → 问 → 等 → 解锁。** 十行代码，一行规则都没有。」 |

**板书建议：** 画调用树：`_on_pointer_down → _do_swap → board.try_swap → gem 动画`，标「Main 管流程 / Board 管规则」。

## 块4 · 匹配判定（board.gd ⑥）⭐

> PPT 显示 `find_match_groups` / `find_matches` / `try_swap`（见 L2-交互与判定.md 块4）
> **先讲伪代码（run 思想）再对照代码**：逐行找 run → 逐列找 run → ≥3 收组 → 去重

| 代码 | 人话（照读） |
|---|---|
| `for row in range(GRID_SIZE): var run_start := 0` | 「**横向扫描开始**：一行一行来。`run_start` 是这一段的起点——从第 0 格开始。」 |
| `while run_end < GRID_SIZE:` | 「**延伸循环**：从起点右边开始，一直往右走。」 |
| `if g == null or g.type != run_type: break` | 「**停的条件**：遇到空位，或者颜色变了——这段 run 到头了。」 |
| `if run_end - run_start >= 3:` | 「**判定**：这段多长？够 3 个就收下——一组三消诞生。」 |
| `run_start = run_end` | 「**不回头**：下一段从这段的**后面**开始找——每颗宝石只被扫一次，又快又不漏。」 |
| `for col in range(GRID_SIZE): ...` | 「纵向扫描——**逻辑一模一样**，只是把行换成列。不信你们课后对照看，就两处下标换了个位置。」 |
| `_add_unique(matched, gem)` | 「**去重**：L 形三消，中间那颗横组竖组都有——收过就跳过。不然它会被消除两次、**分数翻倍**，游戏就穿帮了。」 |
| `if not is_adjacent(a, b): return false` | 「try_swap 第一道检查：**两颗挨着吗？** 不挨着直接拒绝。挨着的定义：横差加纵差等于 1——上下左右；斜对角是 2，不算。`absi` 是绝对值，别写成 `abs`（警告当错误会编不过）。」 |
| `var matches := find_matches()`（try_swap 里） | 「看，今天学的判定**用在哪**：交换动画播完，立刻检查有没有匹配。有，成了；没有，**换回去**——这就是你们看到的『弹回』。」 |

**板书建议：** 写一行格子演示 run：`[红][红][红][蓝][红]` → 起点0延伸、3格收组、起点跳到3继续。再画 L 形图讲去重。
