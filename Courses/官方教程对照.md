## 三、建议补充清单（按优先级）

### 🔴 高优先：gem.tscn 场景实例化（官方灵魂概念）
- **现状**：M1 用纯代码 `new` ColorRect 生成宝石
- **建议**：宝石做成独立场景 `gem.tscn`（根 Node2D + ColorRect 子节点 + gem.gd），board.gd 用 `preload + instantiate() + add_child` 生成 64 个实例
- **教学价值**：这是 Godot 最核心的工作流——「场景即节点类型，可复用可组合」。不学实例化，学员只懂代码生成，不懂 Godot 的哲学
- **成本**：改动不大（board.gd 生成段重写），M1 代码量反而更少
- **顺带收益**：正好讲「根节点反映功能」「为什么 gem 要独立成场景（单一职责/复用）」

### 🟡 中优先：命名规范 + 编辑器技巧
- 官方明确推荐：**类/节点 PascalCase、变量/函数 snake_case、常量 ALL_CAPS**
- 警告图标解读（如 ColorRect 无 size 警告）、锁定子节点防误拖
- 建议写进「教学友好约束」，M1 就执行（零基础第一天养成好习惯）

### 🟡 中优先：HUD 补 CanvasLayer + 锚点
- 官方 HUD 用 CanvasLayer 把 UI 独立成层（不被游戏内容遮挡）
- 锚点 Anchor Presets 定位（ScoreLabel 居中顶部等）
- 第4课时 UI 环节补这两点，比「拖个 Label」专业得多

### 🟢 顺带补：随机数 + Timer + InputMap 概念
- 随机数：M1 生成宝石颜色已用 `randi`，第1课时明确讲
- Timer：进阶扩展加「限时模式」或开场倒计时（借鉴官方 MessageTimer：显示「Ready?」→ 消失）
- InputMap：第2课时讲「动作（action）」概念，点击动作可重映射

### 📚 课后自学链接（不硬塞进课）
- 官方 Dodge the Creeps 完整教程：学员学完三消后跟做，正好互补——三消是「逻辑密集」，官方是「物理/碰撞/动画/敌人」
- 涉及但不适合三消的：Area2D 碰撞、Path2D 路径、AnimatedSprite2D
