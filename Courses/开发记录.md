## 3. M1 · 网格渲染（实现记录）

### 3.1 交付内容

- `project.godot`：640×720、Compatibility 渲染、`click`（鼠标左键）
- `scenes/main.tscn`：`Main → Board`
- `scripts/gem.gd` + 后改为 `scenes/gem.tscn` 场景实例化
- `scripts/board.gd`：二维数组、`grid_to_world` / `world_to_grid`、`find_matches`、`ensure_no_initial_matches`

### 3.2 关键实现细节

- **坐标：** `origin` 使 8×64=512 棋盘在视口居中；`grid_pos` 为 `(col, row)`
- **开局防自消：** 生成后循环 `find_matches`，对匹配格重随机颜色，带安全次数上限
- **宝石创建顺序：** 必须先 `add_child` 再 `setup`（`@onready` 依赖进树）
- **演进：** 先代码里 `ColorRect.new()`，后改为 `gem.tscn` + `preload` + `instantiate()`，对齐官方「场景即可复用类型」教学点

### 3.3 课件可强调的坑

- ColorRect 不设 `size` → 看不见
- 用 `position` 而非误用全局坐标导致错位
- 二维数组越界（0~7）

## 4. M2 · 交互与三消判定

### 4.1 交付内容

- `main.gd`：输入 + 状态雏形（IDLE / SELECTED / SWAPPING…）
- `board.gd`：`try_swap`、`find_match_groups`、`clear_matches`、计分、`score_changed`
- `gem.gd`：选中反馈、交换/消除 Tween
- ScoreLabel（后并入 HUD）

### 4.2 规则约定（课件必须写死）

- **仅「交换后产生匹配」才算成功**；无匹配动画弹回，**不扣步**
- 计分：每组 3 个 = 30，每多 1 个 +10
- 消除后 **留空位**（下落留给 M3）
- 动画期间禁止输入（状态锁）

### 4.3 选中反馈的迭代

| 版本 | 表现 | 结果 |
|------|------|------|
| 初版 | `scale` 放大 | 易挤占邻格，观感差 |
| 现行 | `SelectMask` 半透明白遮罩 | 保留；与拖拽并存 |

### 4.4 重要踩坑：Variant 推断当错误

项目开启「警告当作错误」后：

```text
The variable type is being inferred from a Variant value...
```

**原因：** `abs()` 返回 Variant；`$Board` 标成 `Node2D` 时动态调用也返回 Variant。  

**修复：**

- `abs` → `absi`
- `preload("board.gd")` 作脚本类型，或 `as Gem` 显式转换
- `instantiate() as Gem`

**课件建议：** 单独加一小节「GDScript 类型与警告当错误」，否则学员复制 `abs` 会直接编不过。

## 5. M3 · 下落、连锁与状态机

### 5.1 拆分文件（教学点）

`board.gd` 在 M2 末已偏长，M3 按骨架拆出：

| 文件 | 职责 |
|------|------|
| `board.gd` | 网格、匹配、交换判定、扣步、信号 |
| `board_resolve.gd` | `RefCounted` 辅助类：`resolve_board` / `clear_matches(chain)` / `fall_and_refill` |

Board 持有 `_resolve = ResolveHelper.new(self)`，Tween 建在 Board 节点上（`board.create_tween()`），便于一次 `await`。

### 5.2 流程

```
try_swap（仅判定+可选扣步）
  → 成功则 main 进入 RESOLVING
  → resolve_board：while 有匹配 → clear(×chain) → fall_and_refill
  → 回到 IDLE；若限步且步数为 0 → GAME_OVER
```

- **下落：** 逐列自下而上压实；顶部从网格上方生成再落入  
- **动画：** 同阶段多颗并行 Tween，阶段之间串行  
- **连锁倍率：** 第 n 次消除分数 ×n  
- **下落时长：** `FALL_PER_CELL = 0.08`，按格数近似恒速  

### 5.3 步数策略的变更（对课件很重要）

| 时期 | 策略 |
|------|------|
| M3 初版 | 强制 20 步，用尽 GAME_OVER |
| M4 起 | **限步为可选**；默认无限步，MovesLabel 显示 `∞` |

成功交换才扣步的约定不变；仅在 `moves_limited == true` 时扣步并可能结算。

**问题：** 标题界面下已能看见整盘宝石（`board._ready` 里 `fill_grid`）。  

**现行：**

- `_ready` 只算 `origin`，不生成  
- `new_game` → `reset_game` → `fill_grid`  
- 回标题 → `clear_board()` 清空子节点与 `grid`  
- `get_gem_at` 对空盘直接返回 `null`

### 7.5 体验下沉补丁 v2.1（2026-08-12 · 已归档）

> 定位：把 M5 完整版已验证的「体验硬伤修复」下沉回教学版；**只修体验，不引入扩展**。  
> Prompt 原文已归档：`cursor-prompts/归档/BASIC-v2.1-体验下沉补丁.md`  
> **明确不做：** 特殊宝石 / 模式切换 / 存档 / 提示系统（见 `cursor-prompts/M5-后续优化.md`，本仓库不执行）。

#### 交付四项

| # | 改动 | 文件 | 说明 |
|---|------|------|------|
| 1 | 开局防死局 | `board.gd` | 新增 `has_moves()` / `ensure_has_moves()`；`reset_game` 在 `ensure_no_initial_matches` 之后调用 |
| 2 | 再点取消选中 | `main.gd` | SELECTED 下再点已选中宝石 → `_cancel_drag` + `_deselect` → IDLE（不再误入拖拽） |
| 3 | HUD 亮色 UI | `hud.tscn` 仅资源 | 主按钮亮黄深字、次要/CheckButton 亮蓝、`TitlePanel` 挂在 `Mask` 下随遮罩显隐；**未改** `hud.gd` 逻辑 |
| 4 | 拖拽正式化 | `main.gd` 注释 | 拖拽逻辑本已存在；补交互规则表教学注释（离散点选 vs 连续拖拽并存） |

#### 关键实现笔记

- **`has_moves()`：** 枚举右/下相邻对 → `_swap_grid_data` 模拟 → `find_matches` 验证 → 必须换回。教学点：匹配检测的逆向应用；与 M5 `find_hint_swap` 同族但基础版不实现提示。  
- **`ensure_has_moves()`：** 无解则 `fill_grid` + `ensure_no_initial_matches` 循环，安全上限 100，超出 `push_warning`。  
- **交互共存：** 新选中仍 `_start_drag_on_selected()`；「再点取消」分支直接 return，不启动拖拽；阈值仍 `DRAG_SWAP_THRESHOLD = 28`（不随 M5 放大）。  
- **HUD：** 锁定参数 640×720 / `CELL_SIZE=64`；对局分数条仍浅色字，无需 TopBar。

#### 验收

- Headless 启动通过；连续 `reset_game` 10 局 `has_moves()` 均为 true  
- 再点取消与拖拽/点选交换不冲突；限步、连锁、结算行为与补丁前一致  

#### 教学注释落点（学员可见）

| 教学点 | 位置 |
|--------|------|
| find_matches 逆向 / 可行步检测 | `board.gd` → `has_moves()` |
| 与 `ensure_no_initial_matches` 兄弟关系 | `board.gd` → `ensure_has_moves()` |
| 离散点选 vs 连续拖拽 | `main.gd` → `_on_pointer_down()` 上方规则表 |
| 再点取消选中 | `main.gd` → 取消分支行内注释 |

## 8. 现行架构快照（2026-08-12 · 含 v2.1）

### 8.1 场景树

```
Main (Node2D) [main.gd]
├── Background (ColorRect)          # 深色主背景
├── Board (Node2D) [board.gd]
│   └── Gem 实例 × N（开始后生成）
├── HUD (CanvasLayer) [hud.tscn]
│   ├── Mask (半透明全屏)
│   │   └── TitlePanel (NinePatchRect，亮黄底板；随 Mask 显隐)
│   ├── ScoreLabel / MovesLabel
│   ├── Message / StartButton / MovesLimitedCheck / RestartButton
├── Music (AudioStreamPlayer)
├── SfxClick / SfxSelect / SfxSwap / SfxClear
```

### 8.2 脚本职责

| 脚本 | 职责 |
|------|------|
| `main.gd` | 状态机、点击/拖拽输入、再点取消选中、`new_game`、驱动 resolve、播 SFX/Music |
| `hud.gd` | 显示与按钮；`start_game` / `back_to_title` 信号（亮色样式在 `hud.tscn`） |
| `board.gd` | 网格数据、匹配、交换、限步开关、`ensure_no_initial_matches` / `ensure_has_moves`、`reset_game` / `clear_board` |
| `board_resolve.gd` | 消除（含连锁倍率）、下落填充、连锁循环 |
| `gem.gd` | 类型、SpriteFrames 动画、选中遮罩、交换/消除动画 |

### 8.3 状态机

```
WAITING →（开始）→ IDLE ⇄ SELECTED → SWAPPING → RESOLVING → IDLE
                                              ↘（限步用尽）→ GAME_OVER →（再来一局）→ …
IDLE → 点宝石 → SELECTED（可拖拽）
SELECTED → 再点已选中 → IDLE（取消）
SELECTED → 点相邻 / 拖过阈值 → SWAPPING
WAITING / SWAPPING / RESOLVING / GAME_OVER：锁棋盘输入
```

### 8.4 核心玩法参数（便于课件「作业改数值」）

| 常量/变量 | 含义 | 典型值 |
|-----------|------|--------|
| `GRID_SIZE` | 边长 | 8 |
| `CELL_SIZE` | 格像素 | 64 |
| `MOVES_DEFAULT` | 限步局步数 | 20 |
| `moves_limited` | 是否限步 | 默认 false |
| 基础分 | 3 连 / 每多 1 | 30 / +10 |
| 连锁 | 第 n 波 | ×n |
| `DRAG_SWAP_THRESHOLD` | 拖拽触发 | 28 px |
| `FALL_PER_CELL` | 下落单格时长 | 0.08 s |
| 交换/消除 Tween | 时长 | ~0.15 / ~0.2 s |

## 14. BASIC v3 · 官方化简化（2026-08-13）

> Prompt：`cursor-prompts/BASIC-v3-官方化简化.md`  
> 目标：把教学版复杂度压到接近官方「Your first 2D game (Dodge the Creeps)」——**场景即节点类型、一场景一脚本、贴图资源直接挂在节点上、代码只写行为**。完整版（`godot-match3`）不动；本目录只做减法。

### 14.1 改动总览

| 项 | 改前 | 改后 |
|----|------|------|
| 脚本数 | 5（含 `board_resolve.gd`） | 4（结算合并回 `board.gd`） |
| 宝石表现 | 代码切 SpriteFrames，AnimatedSprite2D 旋转动画 | 场景挂静态 `Sprite2D` 贴图 |
| 交互 | 点选 + 拖拽并存；可选限步 + GAME_OVER | **纯点选**；无限步；无游戏结束 |
| HUD | MovesLabel / 限步勾选 / show_title / show_game_over | 分数 + 开始 + 重开；标题态交给场景预设 |
| BGM | `main.tscn` 内嵌 OggPacketSequence（~1.9MB） | 外部 `assets/House In a Forest Loop.ogg` |

### 14.2 分项记录

**1. 宝石贴图官方化（两轮）**

- **第一轮（v3 Prompt）：** `AnimatedSprite2D` → `Sprite2D`；删掉 `gem.gd` 里 `_build_frames` / 共享 SpriteFrames；贴图以 sheet 的 `AtlasTexture`（各色第一帧）挂在 `gem.tscn` 的 `@export gem_textures`。
- **第二轮（同日优化）：** 6 色改为独立 PNG（`gem_red/blue/green/yellow/purple/orange.png`，52×52，由 sheet 切帧生成）；`gem.tscn` 改为 `ext_resource` 直接引用；**`gem.gd` 不动**（仍按 enum 顺序读 `gem_textures`）。`godot --headless --import` 已生成对应 `.import`。

**2. board：砍限步 + 合并结算**

- 删除 `MOVES_DEFAULT` / `moves_changed` / `moves_left` / `moves_limited` / `GEM_COLORS`
- `reset_game()` 无参；`try_swap` 不再扣步
- `board_resolve.gd` 的 `resolve_board` / `clear_matches` / `_calc_score` / `fall_and_refill` 并入 `board.gd` 末尾后删文件（含 `.uid`）
- **保留：** 防死局（`ensure_no_initial_matches` + `has_moves` + `ensure_has_moves`）、连锁计分 ×n、场景实例化宝石

**3. main：砍拖拽 + 砍 GAME_OVER**

- `State` 仅剩 `WAITING / IDLE / SELECTED / SWAPPING / RESOLVING`
- 删除拖拽全套（阈值、视觉跟随、direction 判定等）
- `_unhandled_input` 只处理左键按下；点选三规则保留（点自己取消 / 相邻交换 / 非相邻换选 / 空白取消）
- `hud.restart.connect(new_game)`：对局中「重新开始」直接开新局，不再回标题；删除 `_on_back_to_title`

**4. HUD 持续简化（两轮）**

- **第一轮：** 删 `MovesLabel` / `MovesLimitedCheck`；`start_game` 无参；`back_to_title` → `restart`；删 `show_game_over` / `update_moves`
- **第二轮：** 因 `hud.tscn` 初始已是标题态、main 亦无「返回标题」，再删 `_ready()` / `show_title()`；文案与初始显隐全部交给场景预设；脚本只留 `prepare_playing` / `update_score` / 两个按钮回调

**5. BGM 外置**

- 重建 `main.tscn`：去掉内嵌 `OggPacketSequence` + 包裹用 `AudioStreamOggVorbis`，`Music.stream` 改为 `ExtResource` 引用外部 ogg
- `main.gd` 的 `_setup_music_loop()` 保留（外部 `AudioStreamOggVorbis` 仍可设 `loop`）

**6. README**

- 玩法改为纯点选 + 无限步；项目结构去掉 `board_resolve.gd`；BGM 说明改为外部引用随仓库提供

### 14.4 交互与状态机（v3 后）

```
WAITING →（开始）→ IDLE ⇄ SELECTED → SWAPPING → RESOLVING → IDLE

WAITING / SWAPPING / RESOLVING：锁棋盘输入

```
