## 实操① · 改 HUD：换按钮样式 + 改游戏标题（15min）

**目标**：让游戏看起来"是你的"——换按钮颜色、改游戏名、调字号

### 操作步骤（打开 `scenes/hud.tscn`）

**1. 换按钮样式（StartButton 主按钮）**

```
选中 StartButton（开始游戏按钮）
→ 检查器 → theme_override_styles
→ normal / hover / pressed 三个槽位
→ 各点「新建 StyleBoxTexture」→ 选择资源：
   assets/ui-kenney/PNG/Blue/Default/button_rectangle_depth_gradient.png（normal）
   assets/ui-kenney/PNG/Blue/Default/button_rectangle_depth_gloss.png（hover/pressed）
```

> 默认是 Yellow 系列（亮黄）；换成 Blue 系列（亮蓝）试试。换完 hover 有高光变化。

**2. 改游戏标题**

```
选中 Message（标题文字）
→ 检查器 → text → 改成你给游戏起的名字
例：「宝石迷阵」→「消消乐」「代码宝石」「三消大师」
```

**3. 调分数显示（可选）**

```
选中 ScoreLabel → theme_override_font_sizes → font_size 22 → 改 26
```

**4. F5 验证**

| 检查项 | 期望 |
|--------|------|
| 标题界面 | 显示你的游戏名 + 换色后的按钮 |
| 点「开始游戏」 | 正常开局，棋盘生成 |
| 对局中 | 分数显示、重开按钮正常 |

### 常见坑

- **改错节点**：RestartButton 也要换色？它现在是 Blue 系列——想统一就把它换回 Yellow（步骤同 1，资源换 Yellow 系列）
- **找不到样式槽**：`theme_override_styles` 下点 `normal` 左边的小箭头展开，不是点文字
- **字体变方块**：不影响运行，导出前要处理（见实操②坑②）

## 实操② · 导出：把游戏变成 exe（15min）

**目标**：导出 Windows exe，双击能玩，发给朋友

### 操作步骤

**1. 装导出模板（仅首次）**

```
编辑器菜单 → 编辑器 → 管理导出模板 → 下载并安装
⚠️ 模板版本必须和引擎版本一致（本项目 Godot 4.7.1）
```

**2. 导出 exe**

```
菜单 → 项目 → 导出…
→ 预设已有 Windows Desktop（export_presets.cfg 配好的）
→ 点「导出项目」→ 选目录（建议 build/）→ 导出
→ 得到 build/GodotMatch3.exe + GodotMatch3.pck
```

**3. 本地验证**

```
双击 GodotMatch3.exe
→ 标题界面（你的游戏名）→ 开局 → 交换 → 连锁 → 重开
→ 音效、BGM 正常，字体正常（不是方块）
```

**4. 发给朋友（可选 Web 版）**

```
exe + pck 两个文件一起发（放同一目录）
——朋友不用装 Godot，双击就能玩

（可选）导出 Web 版：
  项目 → 导出… → 选 Web 预设 → ⚠️ 关闭 thread_support → 导出
  → .html + .wasm → 传 itch.io / GitHub Pages，发链接就能玩
```

### 验证清单（完成后打勾）

| 检查项 | 期望 |
|--------|------|
| exe 双击运行 | 能玩，不用装 Godot |
| 标题 | 你的游戏名 |
| 按钮 | 你换的颜色 |
| 字体 | 正常显示（不丢、不是方块） |
| 音效 / BGM | 正常 |
| 朋友电脑 | 也能跑（跨机器验证） |

### 常见坑（导出三坑）

| 坑 | 现象 | 解法 |
|----|------|------|
| ① 模板版本不一致 | 导出报错/失败 | 装与引擎一致的模板版本 |
| ② 字体丢失 | 导出后文字变方块 | 字体资源（Kenney Future.ttf）→ 检查器 → 勾选「嵌入」 |
| ③ 新素材无 .import | preload 报 unrecognized extension | `godot --path <项目> --headless --import` 生成 .import |
