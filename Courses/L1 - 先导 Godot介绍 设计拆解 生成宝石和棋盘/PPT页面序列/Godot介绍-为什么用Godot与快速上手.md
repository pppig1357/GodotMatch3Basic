# Godot 介绍 · 为什么用 Godot 与快速上手（L1 先导环节）

> **用途**：L1 环境安装环节的讲授内容（Godot 是什么 → 为什么选它 → 方便在哪 → 怎么快速上手）
> **时长**：约 10~15min（配合环境安装实操，先导视频已发过安装流程，现场快讲+答疑）
> **风格**：零基础友好，每节配讲师口播；学员不需要记笔记，跟着感觉走
> **位置**：环境安装环节开场（在"设计拆解"之前或之后均可，建议在拆解之后——先懂游戏再懂工具）

---

## 一、Godot 是什么（3min）

**内容：**
- **免费、开源**的游戏引擎（MIT 协议，任何人随便用，包括商业）
- 2D / 3D 都能做，**2D 是它的看家本领**
- 自带编辑器 + 自带编程语言 GDScript（语法像 Python，超轻量）
- 我们的社课版本：**Godot 4.7**（Steam 版，`E:\Steam\steamapps\common\Godot Engine\`）

**口播：**
「Godot 是一个游戏引擎——就是做游戏用的"工具箱+加工厂"。它最爽的一点：**免费、开源**，一辈子不要钱，做出来的游戏卖了钱也不用分它一分。它 2D 特别强，3D 也能做。写代码用自带语言 GDScript，长得跟 Python 差不多，是主流引擎里最好上手的。咱们社课用的就是 Godot 4.7——你电脑上应该已经装好了（先导视频里有教程）。」

---

## 二、为什么用 Godot（5min）

**内容（对比表）：**

| 对比项 | Godot | Unity | Unreal |
|--------|-------|-------|--------|
| 价格 | **免费开源** | 个人版免费，营收超 20 万美元要授权费 | 游戏营收超 100 万美元抽 5% |
| 2D 能力 | **原生亲儿子** | 2D 是后补的 | 2D 不是强项 |
| 上手难度 | **低**（GDScript 像 Python） | 中（C#） | 高（C++ 为主） |
| 安装包 | **~100MB，秒开** | 几个 GB，启动慢 | 几十 GB |
| 导出 | 一键多平台（Windows/Web/Linux/移动） | 全但流程繁琐 | 全但复杂 |
| 社区 | 独立游戏圈热门，4.x 迭代快 | 最大 | 3A 大厂 |

**口播：**
「为什么咱们选 Godot 而不是 Unity、Unreal？四个字：**零基础友好**。Unity 和 Unreal 都是好引擎，但它们是为"有一定基础的人"设计的——安装几个 G、打开等半天、C#/C++ 先学半年。Godot 安装包一百兆，双击就开，GDScript 三分钟能写第一行。**对你们这些第一次做游戏的人来说，工具越简单，你们离"做出游戏"越近。** 而且 2D 是 Godot 的亲儿子——咱们做的是三消，完美对口。等你们以后想学 Unity（做 3D、找工作），那些知识也不浪费——**引擎是相通的，会了一个，另一个上手很快**（讲师可以举个自己 AllinCards 用 Unity 的例子）。」

## 三、Godot 方便在哪（3min）

**内容（快速上手最实用的几点）：**

1. **打开即用**：不用配环境变量、不用装依赖——下载解压就能跑
2. **四面板一目了然**：场景（左边）/ 节点树（中间）/ 检查器（右边）/ 文件系统（下面）
3. **F5 一键运行**：改完代码按 F5 立刻看到效果——**改→跑→看**，反馈快是学习快的关键
4. **搭积木式组合**：游戏 = 节点树，拖拽节点、挂脚本，不用管"类、命名空间"那套工程概念
5. **脚本就挂在节点上**：选中节点 → 加脚本 → 写逻辑，所见即所得

**口播：**
「Godot 方便在哪？就讲最实用的五条：**打开即用**（零配置）、**四面板**（界面就四块，记住名字就行）、**F5 一键运行**（改完立刻看到效果——今天你们会按无数次 F5）、**搭积木**（游戏就是节点树，拖出来就能用）、**脚本挂节点**（不用学"类啊命名空间啊"那套劝退的东西）。这五条记住，今天够用了。」

---

## 四、怎样快速上手（3min）

**内容（我们的路径，不啃文档）：**

1. **跟社课走**：4 节课 = 4 个可运行成果——今天看到棋盘 → 下节课能消 → 再下节课能连锁 → 最后一节打包成 exe 发给朋友
2. **每课一个"小胜利"**：不用懂全部，每节课学一点点、跑起来一点点
3. **抄代码不丢人**：第一节课大家直接抄代码块，抄完跑起来就是成功——**先跑起来，再慢慢懂**
4. **课后自学指路**：学完 4 节课，可以跟官方教程（Dodge the Creeps）做第二个游戏——到时候你们已经会读代码了
5. **环境准备**：Godot 4.7 装好 + 打开咱们的项目（先导视频演示过）

**口播：**
「怎么快速上手？答案很反直觉：**别先啃文档，先做游戏**。咱们 4 节课，每节课你都会得到一个"能玩的东西"——今天结束你能看到棋盘，下节课你能亲手消宝石。第一节课大家直接抄代码就行，**抄完能跑就是胜利，理解是后面的事**。等 4 节课学完，你们已经会读代码、会改代码了，那时候再跟官方教程做第二个游戏，就轻松了。**先跑起来，再慢慢懂——这是做游戏最快的学习路径。**」

## 五、讲师备注

- **衔接**：这节结尾说「工具准备好了，游戏也拆完了——接下来我们开始造第一个棋盘」→ 进实操①
