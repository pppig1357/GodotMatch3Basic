## 块1 · 宝石场景 gem.tscn（实操①）

```tscn
[gd_scene load_steps=8 format=3]

[ext_resource type="Script" uid="uid://bft8bq3jrx54n" path="res://scripts/gem.gd" id="1_gem"]
[ext_resource type="Texture2D" path="res://assets/sprites/gems/gem_red.png" id="2_red"]
[ext_resource type="Texture2D" path="res://assets/sprites/gems/gem_blue.png" id="3_blue"]
[ext_resource type="Texture2D" path="res://assets/sprites/gems/gem_green.png" id="4_green"]
[ext_resource type="Texture2D" path="res://assets/sprites/gems/gem_yellow.png" id="5_yellow"]
[ext_resource type="Texture2D" path="res://assets/sprites/gems/gem_purple.png" id="6_purple"]
[ext_resource type="Texture2D" path="res://assets/sprites/gems/gem_orange.png" id="7_orange"]

[node name="Gem" type="Node2D"]
script = ExtResource("1_gem")
gem_textures = Array[Texture2D]([ExtResource("2_red"), ExtResource("3_blue"), ExtResource("4_green"), ExtResource("5_yellow"), ExtResource("6_purple"), ExtResource("7_orange")])

[node name="Sprite" type="Sprite2D" parent="."]
scale = Vector2(1.2308, 1.2308)
texture = ExtResource("2_red")
centered = false

[node name="SelectMask" type="ColorRect" parent="."]
visible = false
offset_right = 64.0
offset_bottom = 64.0
mouse_filter = 2
color = Color(1, 1, 1, 0.45)
```

**讲师讲什么：**
- 一个 .tscn 文件 = 一颗宝石的"图纸"：一个 Node2D 根节点 + 两个子节点
- **贴图 = 场景里挂的资源**：Sprite2D 的 texture 槽拖进去一张 PNG（不是代码画的！）
- `gem_textures` 数组：6 张图按顺序（红蓝绿黄紫橙）挂好，代码里 `gem_textures[0]` 就是红色
- SelectMask：半透明白色遮罩，选中时亮起（先埋个伏笔，第2课用）
- 52px 贴图 × 1.2308 缩放 = 64px 格子（`scale` 已经算好写死在场景里）

**学员注意：** 现在先别改这个文件，只是"看懂图纸"。

## 块2 · 宝石脚本 gem.gd —— 类型与贴图

```gdscript
class_name Gem

## 六种宝石颜色（枚举 = 一组有名字的整数常量）
## RED=0, BLUE=1, GREEN=2, YELLOW=3, PURPLE=4, ORANGE=5
enum GemType { RED, BLUE, GREEN, YELLOW, PURPLE, ORANGE }

## 六色贴图数组：在 gem.tscn 场景里按 enum 顺序挂好 6 张 PNG
@export var gem_textures: Array[Texture2D] = []

## 当前宝石类型（默认红色）
var type: int = GemType.RED
## 网格坐标 (col, row)——它在棋盘的哪一格
var grid_pos: Vector2i = Vector2i.ZERO

@onready var _sprite: Sprite2D = $Sprite
@onready var _select_mask: ColorRect = $SelectMask

## 初始化：设置类型 + 网格坐标（由 board._spawn_gem 在创建时调用）
func setup(gem_type: int, pos: Vector2i) -> void:
	type = gem_type
	grid_pos = pos
	set_type(gem_type)      # 立刻换上对应颜色的贴图

## 更换类型：换一张贴图
func set_type(gem_type: int) -> void:
	type = gem_type
	_sprite.texture = gem_textures[gem_type]   # 从数组里取对应颜色的贴图
```

**讲师讲什么：**
- `enum` = 给颜色起名字的编号：代码里写 `GemType.RED` 比写 `0` 好懂一万倍
- `type` 存的是编号（0~5），`set_type` 用它去贴图数组里取图
- `@onready`：等节点进场景树后才取子节点——所以创建宝石必须"先进树再 setup"（呼应块7）
- **换色 = 一行代码**：`set_type(3)` 就变黄色（贴图跟着换）

## 块3 · 棋盘常量与数据（board.gd 开头）

```gdscript
const GRID_SIZE := 8        # 8 列 × 8 行
const CELL_SIZE := 64       # 每格边长 64 像素，棋盘总尺寸 512×512

## 宝石场景（图纸）——instantiate() 复制出真实宝石
const GEM_SCENE := preload("res://scenes/gem.tscn")

## 二维数组 grid[col][row]：第一维列，第二维行；元素 = Gem 或 null（空位）
var grid: Array = []
## 棋盘左上角的世界坐标（用于居中）
var origin: Vector2 = Vector2.ZERO
## 当前分数
var score: int = 0
```

**讲师讲什么：**
- `const` = 常量（不能改），`GRID_SIZE := 8` 改这里，整个棋盘就变——**这就是实操②要改的地方**
- `grid[col][row]`：先列后行（先横后竖的直觉相反，重点强调！）
- `preload`：提前加载 gem.tscn 图纸，随时能 instantiate

## 块4 · 坐标换算（棋盘怎么摆到屏幕中间）

```gdscript
## 让 512×512 棋盘在窗口（640×720）中居中
func _compute_origin() -> void:
	var board_pixels := GRID_SIZE * CELL_SIZE   # 512
	var vp := get_viewport_rect().size          # 窗口尺寸 (640, 720)
	origin = Vector2(
		(vp.x - board_pixels) / 2.0,    # (640-512)/2 = 64
		(vp.y - board_pixels) / 2.0     # (720-512)/2 = 104
	)

## 网格坐标 → 世界坐标：第 (col,row) 格的左上角像素位置
func grid_to_world(pos: Vector2i) -> Vector2:
	return origin + Vector2(pos.x, pos.y) * CELL_SIZE
```

**讲师讲什么：**
- 为什么需要换算：棋盘的格子是"逻辑坐标 (col,row)"，屏幕上要"像素坐标"
- `origin` = 棋盘左上角，居中 = 让棋盘上下左右的空白一样多
- `grid_to_world(0,0)` = 左上角第一格；`grid_to_world(7,7)` = 右下角
- 伪代码版：`像素位置 = 棋盘左上角 + 格子坐标 × 格子大小`

## 块5 · 生成棋盘 fill_grid（核心）

```gdscript
## 清空旧棋盘，重新铺满 8×8 随机宝石
func fill_grid() -> void:
	for child in get_children():        # 删掉棋盘上所有旧宝石节点
		child.queue_free()
	grid.clear()                        # 清空数据表
	for col in range(GRID_SIZE):        # 外层循环：逐列（8 列）
		var column: Array = []
		for row in range(GRID_SIZE):    # 内层循环：该列的逐行（8 行）
			var pos := Vector2i(col, row)
			column.append(_spawn_gem(random_gem_type(), pos))
		grid.append(column)
```

**讲师讲什么：**
- **双层 for 循环 = 64 次**：8 列 × 8 行，每次生成一颗宝石——这是"生成棋盘"的全部秘密
- `grid.clear()` + 删节点：先清场再重铺（重复调用不会叠两层）
- 伪代码版：`for 每列: for 每行: 在(col,row)放一颗随机色宝石`
- **改动观察点**：`GRID_SIZE` 改 10 → 10×10 = 100 颗

## 块6 · 随机颜色 random_gem_type

```gdscript
## 随机一种宝石类型：randi() 随机整数 % 6 → 0~5，正好对应 GemType 六色
func random_gem_type() -> int:
	return randi() % 6
```

**讲师讲什么：**
- `randi()` 产生一个很大的随机整数，`% 6` 取余数 → 0~5 六种可能
- 0~5 刚好对应 `GemType` 枚举的 RED~ORANGE（呼应块2）
- 作业预告：改成 `% 5` 就只剩五种颜色（课后作业）

## 块7 · 创建单颗宝石 _spawn_gem（场景实例化 ⭐）

```gdscript
## 创建一颗宝石实例：先 add_child 进场景树，再 setup
func _spawn_gem(gem_type: int, pos: Vector2i) -> Gem:
	var gem: Gem = GEM_SCENE.instantiate() as Gem   # 按"图纸"复制实例
	gem.position = grid_to_world(pos)               # 摆到正确格子
	add_child(gem)                                  # 挂到棋盘节点下（必须先进树）
	gem.setup(gem_type, pos)                        # 设置颜色类型和网格坐标
	return gem
```

**讲师讲什么：**
- **场景实例化（本课最重要概念）**：gem.tscn 是"图纸"，`instantiate()` 是"照着图纸造产品"——64 颗宝石 = 同一张图纸造 64 次
- 类比：月饼模具（图纸）→ 压出 64 个月饼（实例）
- 三步顺序：定位置 → 进场景树 → 初始化（顺序不能反，呼应块2 的 @onready）
- 为什么用场景而不是代码画：图纸可以随时改（加动画、改贴图），64 颗全跟着变

## 块8 · 去初始三消 ensure_no_initial_matches（"不重复"关键 ⭐）

```gdscript
## 保险①：开局消除初始三消——有匹配就把那颗换随机色，直到棋盘稳定
func ensure_no_initial_matches() -> void:
	var safety := 0
	while safety < 100:
		var matches := find_matches()           # 找出当前所有匹配
		if matches.is_empty():
			return                              # 没有匹配了，稳定，结束
		for gem in matches:                     # 有匹配 → 每颗换随机色
			(gem as Gem).set_type(random_gem_type())
		safety += 1
	push_warning("ensure_no_initial_matches: 超过安全次数仍有匹配")
```

**配套（依赖的判定函数，PPT 只展示思路不展开）：**

```gdscript
## 找出所有匹配组：每组是连续 ≥3 个同色宝石
## 算法思路：逐行扫连续同色段 ≥3 → 逐列同样 → 汇总
func find_match_groups() -> Array: ...   # 完整实现见 scripts/board.gd ⑥

## 把匹配组摊平成宝石数组（去重）
func find_matches() -> Array: ...
```

**讲师讲什么：**
- **为什么需要它（"不重复"的由来）**：纯随机可能铺出"红红红"——游戏一开局就自动消除，学员会以为代码写错了
- 解法思路：铺完 → 检查有没有匹配 → 有就把那几颗换色 → 再检查，循环到没有为止
- `while` 循环：反复检查直到稳定；`safety < 100` 是安全阀（防止死循环）
- **第2课预告**：这个"检查匹配"的 `find_matches` 是核心算法，下节课细讲
