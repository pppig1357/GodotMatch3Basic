## 块1 · 动画三件套（gem.gd ④，模板 T3）

> PPT 显示三个动画函数（见 L3-游戏循环.md 块1），配合 `L3-动画下落样板.md` 页 4 使用

| 代码 | 人话（照读） |
|---|---|
| `func animate_swap_to(target)` | 「滑动交换：0.15 秒从当前位置滑到 target。第 2 课你们见过它干活——交换动画就是它。」 |
| `var tween := create_tween()` | 「**Tween = 动画调度器**：Godot 的动画工具，一句 `tween_property` 就让一个属性平滑变化。」 |
| `tween.tween_property(self, "position", target, 0.15)` | 「把 `position`（位置）在 0.15 秒内变成 target——这就是"滑动"的本质：位置随时间平滑变化。」 |
| `await tween.finished` | 「**T3 模板，全课最该背的一句**：等动画播完才继续。不写它，动画播到一半下一段就开始了——宝石会乱飞。」 |
| `tween.set_parallel(true)`（animate_clear） | 「并行模式：缩小和淡出**同时**进行。注意：这是『一个动画内部』的并行，跟『动画之间串行』不冲突。」 |
| `tween.tween_property(self, "modulate:a", 0.0, 0.2)` | 「modulate:a = 透明度。0.0 = 完全透明——配合缩小，就是"缩小消失"的效果。」 |
| `func animate_fall_to(target, duration)` | 「下落动画：时长由调用方传入——落得远就久。为什么不能写死 0.15？落 1 格和落 5 格用同样时间，速度就忽快忽慢，不像重力。」 |

**板书建议：** 写 T3 模板大字：`await tween.finished`，旁边画时间轴（动画条 → await 停顿 → 下一段）。

| 代码 | 人话（照读） |
|---|---|
| `var chain := 1` | 「连锁计数器，从 1 开始。第 1 次消除 ×1，第 2 次 ×2——记住这个数，等会儿计分要用。」 |
| `while true:` | 「无限循环——只要不主动退出就一直转。为什么不用『有匹配才进』？因为我们要**先检查再决定**，这更安全。」 |
| `var matches: Array = find_matches()` | 「每次循环先问：现在还有没有匹配？——第 2 课学的判定，在这被反复调用。」 |
| `if matches.is_empty(): break` | 「没了？**break 跳出循环**，结算结束。这是唯一的出口。」 |
| `await clear_matches(matches, chain)` | 「有匹配：消除 + 计分。await = 等消除动画播完才继续。」 |
| `await fall_and_refill()` | 「然后下落 + 补新。也是等动画播完。」 |
| `chain += 1` | 「连锁次数 +1，回循环开头再检查——**这就是连锁**：消完可能又凑出新三消。」 |

**板书建议：** 画循环图：`检查 → 消除 → 下落 → 回检查`，标"chain 每次 +1"。

## 块3b · _calc_score（实操：人生第一个函数）

| 口播 |
|------|
| 「现在写人生第一个函数。需求：每组 3 个 = 30 分，多 1 个 +10。函数签名我写好了，你们填函数体。三个零件：**for 遍历每组**、**group.size() 数个数**、**total += 累加**。条件判断：个数 ≥3 才算分。」 |
| 「讲师先完整写一遍——`var total := 0` 存总分；`for group in groups:` 一组一组来；`if n >= 3:` 够 3 个才加分；`total += 30 + (n - 3) * 10` 公式；最后 `return total`。」 |
| 「验证：消除 3 连 = 30 分，4 连 = 40 分。写不出来就对照我写的抄一遍，抄完改成自己的——**抄也是一种学习**。」 |

**防手抖速查：**
- 忘写 `return total` → 报错（函数声明了 `-> int` 必须返回）
- `group.size()` 写成 `group.size` → 报错（少括号）
- 空数组传入 → 循环不执行，返回 0（正常，不报错）

## 块4 · fall_and_refill（下落填充，伪代码先行）

| 代码 | 人话（照读） |
|---|---|
| `var movers: Array = []` | 「先开个**记账本**：每颗要动的宝石记一行——谁、落到哪、花多久。先记账，最后统一播动画。」 |
| `for row in range(GRID_SIZE - 1, -1, -1)` | 「自下而上扫——**必须从底部往上**，不然宝石会"卡"在半路。像往杯子里倒沙子，从底下压实。」 |
| `grid[col][row] = null; grid[col][write_row] = gem` | 「数据搬移：原位置清空、新位置填入。画面还没动，**数据先动**——第 2 课的老套路：数据与表现分离。」 |
| `maxf(FALL_PER_CELL, float(cells) * FALL_PER_CELL)` | 「时长按格数算：落 1 格 0.08 秒，落 3 格 0.24 秒——**落下越快，视觉越自然**（恒速）。」 |
| `var start_pos := Vector2i(col, -1 - spawn_index)` | 「新宝石从屏幕外上方（行 -1、-2…）排队落入——像补货机往货架上补货。」 |
| `tween.set_parallel(true); for item in movers: ...` | 「记账本一次性兑现：一个并行 Tween 同时播放所有下落动画，await 一次搞定。」 |

**板书建议：** 画一列宝石下落示意：空洞在下 → 上面宝石压实 → 顶部补新（从 -1 行落入）。
