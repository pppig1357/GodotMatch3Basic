## 页面 2/6 · 伪代码先行 —— 结算循环（模板 T2 ⭐）

**标题：** 先看循环：消除 → 下落 → 再检查（连锁的秘密）

**页面内容（伪代码 + 图示）：**

```
结算开始
│
└─ while true（无限循环）:
     ├─ 检查：还有匹配吗？
     │    ├─ 没有 → break（结算结束）
     │    └─ 有 → 继续：
     │         ├─ 消除 + 计分（第 1 次 ×1，第 2 次 ×2，第 3 次 ×3…）
     │         ├─ 下落 + 顶部补新
     │         └─ 回循环开头再检查 ← 连锁！
```

**配图（连锁演示）：** 三消 → 消 → 下落 → 又三消 → 再消 → 又下落……（×2 ×3 分数飙升）

**人话：** 连锁 = **循环重复**。一次消除可能引发新的匹配（因为下落重新排列了宝石）——循环就是"只要还有得消就继续消"。

**代码地图标签：** 📍 伪代码 ↔ `board.gd` → ⑨ resolve_board

**讲师口播：**
「看这个循环——`while true` 无限循环，每次做三件事：**检查有没有匹配 → 有就消除计分 → 下落补新**，然后回到开头再检查。为什么还要检查？因为下落之后宝石重新排列，可能又凑出新三消——这就是连锁。`chain` 这个数每次 +1，第 2 次消除分数 ×2，第 3 次 ×3——**连锁越深，分数越爆炸**。这就是三消游戏让人上头的核心机制。」

## 页面 3/6 · 全貌页 —— resolve_board 真实代码

**标题：** resolve_board —— 循环的代码长这样（10 行）

**页面内容（完整代码）：**

```gdscript
func resolve_board() -> void:
	var chain := 1
	while true:
		var matches: Array = find_matches()
		if matches.is_empty():
			break                        # 没有匹配了，结算结束
		await clear_matches(matches, chain)   # 消除 + 计分
		await fall_and_refill()               # 下落 + 顶部补新
		chain += 1                            # 连锁次数 +1
```

**对照提示：** 跟伪代码一模一样——检查（find_matches）→ 消除（clear_matches）→ 下落（fall_and_refill）→ 循环。

**代码地图标签：** 📍 `board.gd` → ⑨ 结算循环

**讲师口播：**
「十行代码，跟伪代码一模一样。`await` 还记得吗？第 2 课讲过——等动画播完再继续。消除动画播完才下落，下落动画播完才回循环开头。**顺序不能乱**，这就是串行。」

## 页面 4/6 · 模板 T3 —— 动画串行（await 是刹车）

**标题：** 为什么动画必须"等"？（T3 模板）

**页面内容（对比 + 代码）：**

```
❌ 错误：不等动画
   消除动画播到一半 → 开始下落 → 宝石位置错乱 → 穿帮

✅ 正确：await 串行
   消除动画 await 播完 → 下落动画 await 播完 → 下一步
```

```gdscript
## 动画②：消除（缩小 + 淡出同时进行）
func animate_clear() -> void:
	var tween := create_tween()
	tween.set_parallel(true)                    # 并行模式：两个效果一起播
	tween.tween_property(self, "scale", Vector2(0.2, 0.2), 0.2)
	tween.tween_property(self, "modulate:a", 0.0, 0.2)
	await tween.finished                        # 等这组动画播完（T3 模板）
```

**人话：**
- **T3 模板（可背）**：`await tween.finished`——动画必须等播完再继续
- **并行 vs 串行**：一个动画内部可以并行（缩小+淡出一起），动画之间必须串行（消除完才下落）
- 反例：clear_matches 里多颗宝石同时消除——用并行 Tween + 只 await 第一颗（技巧）

**代码地图标签：** 📍 `gem.gd` → ④ 动画三件套

**讲师口播：**
「动画的世界里有个铁律：**必须等上一段播完才能播下一段**。不信你试试不等——宝石还在半空中就开始下一段，位置全乱。T3 模板就一句话：`await tween.finished`。注意区分：**一个动画内部**可以并行（缩小和淡出同时），**动画之间**必须串行（消除完才下落）。」
