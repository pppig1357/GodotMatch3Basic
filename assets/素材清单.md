## 三、音效与 BGM

### 音效
见上表 `ui-kenney/Sounds/`（4 个 ogg，来自 Kenney UI Pack）。

### BGM：House In a Forest Loop
- **来源**：**Godot 官方示例项目「Dodge the Creeps」（官方教程 Your first 2D game 配套）自带**——pppig 从 Godot 引擎安装目录的官方示例中取得；原作者 **Kenney**（[Music Jingles](https://kenney.nl/assets/music-jingles)，CC0）
- **实现方式（⚠️ 注意）**：当前 BGM 音频数据**内嵌在 `scenes/main.tscn`**（`OggPacketSequence` sub_resource，packet_data 约 1.9MB），由 `main.gd` 的 `$Music`（AudioStreamPlayer）播放并设循环。因此 `assets/` 下**没有**外部 BGM 文件
- **教学提示**：若想把「引用外部音频资源」作为教学点，可让 Cursor 把 tscn 内嵌数据改为 `ext_resource` 引用外部 .ogg（素材可从完整版 `godot-match3` 的 `assets/Music - loop/` 取，完整版保留有外部文件）
- 音量建议 0.3~0.5，不盖过音效

> 已清理（未引用）：
> - `assets/audio/bgm/`（`bgm_main.ogg` 8-Bit NES / `bgm_alt_pizzi.ogg` 备选——v2 时代的默认方案，已被 House In a Forest Loop 取代）
> - `assets/Music - loop/`（外部 BGM 文件——音频数据已内嵌进 main.tscn，运行时零依赖）
> - `assets/bgm-kenney/`（Kenney Music Jingles 全量 85 首——M5 特殊宝石音效用 `jingles_HIT06/10/14`，教学版不需要）
